Layers 2/3/5/8 are pure functions of the serialized-DOM string that layer 1 hashes — an identical hash genuinely implies identical inputs for them. Layer 4 is *not* a function of that string: its inputs are screenshot pixels produced by Chromium rendering, which include externally-referenced asset bytes (`<img>`/CSS-referenced images, external JS painting over the page after load, cross-origin iframe internals) that never appear in `page.content()`. The gate's justification ("a byte-identical page could only differ visually through non-deterministic rendering noise") treats DOM identity as pixel identity — false exactly for server-side asset replacement, the most common low-sophistication defacement class. The missing primitive is the predicate distinction "layer input ⊆ hashed content" vs "layer input independent of hashed content".
