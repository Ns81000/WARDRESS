# =============================================================================
# Wardress PROMPT-002 Phase 13 — end-to-end capture validation site list.
#
# Extends `wardress-test-sites (1).txt` (the 88-URL seed) with additions aimed
# at the failure modes the Phase-13 gate must stress (SPA JS rendering,
# Cloudflare WAFs, lazy/infinite scroll, consent banners, non-Latin text,
# government/high-security hardening, e-commerce churn) AND keeps the strongest
# carries from that seed.
#
# Format contract (parsed by tests/test_capture_e2e.py — do not break it):
#   - Section headers are exactly `# SPA/JS Heavy`, `# Cloudflare`,
#     `# Lazy Loading`, `# Cookie Banner`, `# Non-Latin`, `# Gov/Security`,
#     `# Static Control`, `# E-commerce` (the reporting-table categories).
#   - Every non-comment, non-blank line under a header is a URL belonging to
#     that category. No inline comments on URL lines.
#   - Each site is classified by its PRIMARY stress axis for this validation;
#     many sites legitimately fit more than one category (a news site with a
#     consent banner is both "news" and "cookie banner" — it is listed where
#     the gate needs it). That is intentional.
#   - Counts must meet the Phase-13 minimums (10 SPA / 5 Cloudflare /
#     10 lazy-loading / 10 cookie-banner / 5 non-Latin / 5 gov / 5 static /
#     5 e-commerce); the e2e gate asserts them and collection fails if a
#     section name is misspelled.
# =============================================================================
